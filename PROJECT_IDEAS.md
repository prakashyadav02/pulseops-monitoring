# Recommended FastAPI + React portfolio projects

| Project | What it teaches | Level |
|---|---|---|
| **PulseOps — API Monitoring & Incident Management** (included) | Scheduled jobs, HTTP/networking, databases, analytics, state transitions, alerts | Advanced |
| **AI Customer Support Desk** | Ticket routing, agent assist, RAG, human review, vector search | Advanced |
| **Job Application Tracker** | Authentication, workflows, document uploads, scheduled reminders, AI matching | Intermediate |
| **Inventory & Order Management** | Transactions, concurrency, RBAC, stock reservations, reports | Intermediate/Advanced |
| **Team Project Management (mini Linear)** | Kanban UI, workspaces, comments, WebSockets, notifications | Intermediate |
| **Expense Tracker & Budget Analytics** | REST CRUD, queries, categories, charts, exports | Beginner/Intermediate |

PulseOps is a strong first choice when demonstrating backend design *and* an attractive React dashboard: monitoring and incident lifecycles require actual business logic beyond CRUD.
